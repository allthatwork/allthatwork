**Applications** is where you keep track of the jobs you're going for. Each application holds the role, the company, the saved job posting, the resume and letter you sent, your contacts, notes and a dated history. It also works out what each application needs next, such as an interview coming up or a follow-up that's due.

For focused work on one job, open its details and select **Open workspace**. [Career and Application Workspaces](/guides/career-overview) explains Fit, Apply, interview preparation, practice, replies and saved results. Shared experience and search schedules live under **Career**.

To open it, select **Applications** in the sidebar (on a phone, it's in the bottom tab bar).

## How stages work

Every application sits in one stage. The first five stages form a pipeline you move through in order:

| Stage         | Use it when                                                              |
| ------------- | ------------------------------------------------------------------------ |
| **Saved**     | You found the job but haven't applied yet.                               |
| **Applied**   | You sent your application.                                               |
| **Screening** | A recruiter or hiring manager got back to you, or you have a first call. |
| **Interview** | You're in the interview process.                                         |
| **Offer**     | You received an offer.                                                   |
| **Closed**    | The application ended, whatever the outcome.                             |

You can close an application from any stage. Closing asks for a reason (**Not selected**, **I withdrew**, **Accepted another offer** or **No response**), which Insights uses later. Closed applications are hidden until you add **Closed** in the **Stage** filter (see [Finding applications](#finding-applications)). See [Managing an application](/guides/managing-an-application#closing-an-application).

<Note>
  When an application with a linked resume or letter reaches **Applied** or a later stage, Reactive Resume saves a copy
  of each as a "Sent to *company*" version. You can always open exactly what you sent, even after you keep editing the
  document.
</Note>

## Choosing a view

Use the tabs above the list to switch views. Your choice is kept in the page address, so a bookmark opens the same view.

<Tabs>
  <Tab title="Board">
    The default view. One column per stage, with a card for each application. A card shows the search fit (`Fit NN%`) and the resume **Build** status next to the next step; select **Build** on a card to queue or unqueue it for a targeted resume build. Drag a card to another column to move it to that stage. Each card also has a **⋯** menu with **Move to…**, **Close…** and **Delete…**, which is handy if you prefer the keyboard. The columns follow the **Stage** filter, so with **Closed** included a **Closed** column appears too, and with one stage chosen you get one column on the left. Dragging a card there asks why it ended before closing it, so Insights can use the outcome.

    The columns share the page's width evenly and the board fills the window's height, with each column scrolling on its own. On a narrower window the columns keep a minimum width and the board scrolls sideways; a fade on the edge shows there are more columns that way. Dragging a card toward the edge scrolls the board too.

  <Tab title="List">
    Applications are grouped by stage in the order that usually needs you first: **Interview**, **Offer**, **Screening**, **Applied**, **Saved**, then **Closed** when the **Stage** filter includes it. Only the stages the filter shows get a group.

    - Select a group heading to collapse or expand it.
    - Select the **Role**, **Next step**, **Fit** or **Updated** column heading to sort within each group. Select it again to reverse the order. The sort is kept in the page address with the filters. **Fit** is the search fit; applications without one sort last when sorting highest first.
    - The **Next step** column shows the next interview, the follow-up you set, or how long you've been waiting. It turns amber when something is overdue or you've had no reply for 10 days or more (you can change the number of days or turn this off in **Settings → Preferences → Reminders**).
    - The **Sent** column shows an icon for a linked resume and a linked letter. It says **None** in amber when an application was sent without a linked document.
    - Select a row to open its details.

  </Tab>
  <Tab title="Insights">
    Charts about how your applications are going: how far they get, how often and how quickly people reply, and where your applications come from. See [Viewing application insights](/guides/viewing-application-insights).
  </Tab>
  <Tab title="Calendar">
    A month calendar of your interviews, with a list of upcoming ones beside it. See [Scheduling interviews](/guides/scheduling-interviews).
  </Tab>
</Tabs>

On phones, the page shows **List** and **Insights** only (it opens on List), and list rows show the company and next step on a second line.

## Finding applications

Type in **Search applications** to filter as you type. Search looks at the role, company, location, contact names and tags.

After the search box there's a button for each filter. Select one to open it, tick what you want, and the page shows only the applications that match. Within one filter, ticked values mean "any of these"; different filters combine, so **Build: Built** and **Found by: Dorel** shows built applications that Dorel found.

| Filter       | Shows applications                                                                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stage**    | In the stages you tick. It starts at the five open stages ("Stage: Open"); add **Closed** to see closed ones. **All stages** ticks all six.                     |
| **Build**    | By resume build status: **Not queued**, **Queued**, **Building**, **Built** or **Failed**.                                                                      |
| **Found by** | Found by who or what you tick, or **Not set**.                                                                                                                  |
| **Lane**     | Aimed at the lanes you tick (your lanes from **Preferences**, plus any others in use), or **No lane**. It matches either lane unless you pick **Primary only**. |
| **Fit**      | With a search fit or targeting fit of at least 80+, 85+ and so on, or **None yet** for the ones without.                                                        |

**More filters** adds five more: **Found on**, **Documents** (a linked resume or cover letter, or none), **Needs attention** (no reply for a while, a follow-up that's due, an interview coming, questions to answer), **Dates** (added or updated in the last 7, 14 or 30 days) and **Tags**. In Tags, select **+** for a tag the application must have and **−** for one it must not have; with two or more **+** tags, choose **Any of** or **All of** them.

- Each option shows how many applications you'd get if you picked it, given the other filters. Options at 0 stay in the list, greyed.
- A set filter turns blue and shows its value. Select its **×** to clear just that one. **Clear all**, at the end of the row, clears every filter and the search, and says how many applications show out of the total.
- The filters are kept in the page address, so reloading, going back, a bookmark or a copied link keeps them.
- The browser tab remembers its filters too: going to **Applications** from the sidebar, or back from an application's workspace, brings back the filters you last used in that tab. A new tab starts with the open stages only.
- If you change an application so it no longer matches (say you select **Build** on a card while showing **Build: Not queued**), it stays where it is, faded, with "Doesn't match the filters now", until you change the filters or reload. That way you can work through a filtered list without cards jumping away.
- If nothing matches, select **Clear filters**.
- On a phone, select **Filters** to open them all in one sheet. The filters you set show as chips under the search box, each with an **×**.

The Board, List and Calendar follow the filters, and **Export to CSV** exports what they show. Insights always counts every application, so it hides the search and the filters.

## Acting on several applications at once

In the List view on a computer or tablet, select the checkboxes next to the applications you want. A bar appears at the bottom of the page with:

- **Move to…** to move them all to one stage
- **Add tag** to add the same tag to each
- **Close…** to close them all with one reason
- **Delete…** to delete them permanently (you're asked to confirm)
- **Clear** to deselect

Selection follows the visible rows. Filtering out a stage, collapsing a stage or changing the search removes hidden selections before a bulk action.

## Follow-up reminders

When an application has been at **Applied** for 10 days or more without a reply, a reminder appears above the list for the one that has waited longest, for example "Harborlight Labs: no reply for 17 days." Select **Open** to go to that application, or **×** to dismiss the reminder. Dismissing is remembered in this browser, so that application's reminder doesn't come back here.

To wait longer before the reminder, or to stop these reminders altogether, go to **Settings → Preferences → Reminders**. See [Choose your reminders](/guides/changing-appearance-and-language#choose-your-reminders).

## Opening Applications from anywhere

Press <kbd>⌘</kbd> <kbd>K</kbd> (<kbd>Ctrl</kbd> <kbd>K</kbd> on Windows and Linux) and choose **Applications** to go to the page or to search your applications by company or role. Run **New Application** to open the add dialog. See [Using the command bar](/guides/using-the-command-bar).
